# Halo / 博客浮动状态组件（0.15）

在 Halo Console → 系统设置 → 代码注入 → 页脚，添加以下完整片段。先在客户端或网页的“公开展示”选择所需账号的公开字段并保存，把 `alice` 换成实际账号名：

```html
<state-of-me-status endpoint="/presence/v1/public/users/alice"></state-of-me-status>
<script defer src="/presence/widget.js?v=0.15.0"></script>
```

`endpoint` 必须写在 `state-of-me-status` 元素上，不能写在 script 上。必须同时添加元素与脚本，并为元素填写具体账号的公开地址。

每个博客域名必须把同源 `/presence/*` 去掉 `/presence` 前缀后代理到 State of Me。跨域 URL 被组件主动拒绝，因此不能只把脚本 URL 改成另一域名；同源代理配置见 [快速入门](../../docs/QUICKSTART.md)。组件不发送凭据或 Cookie。只通过公开接口取数，不要往网页填任何设备、只读或机器人密钥。

组件默认右下方收起，支持拖动、方向键移动、展开/收起、歌词折叠和恢复位置，跟随博客明暗与文字颜色。按设备和类别折叠展示账号实际公开的全部字段：应用、设备与电源、活跃状态、网络、声音、系统资源、显示环境、WhatPulse、采集诊断和媒体。未知新增字段以安全文本展示，不要求重写卡片。设备名称未授权时使用“设备 1”等通用编号。每台正在播放的设备分别展示媒体；标题、歌词、进度独立授权，缺失信息不会补成 0 或猜测。歌词窗口最多 16 行、未来 60 秒；页面连续推进，5 秒校准，超过实时有效期清空。历史统计独立显示每日汇总、应用排行与小时分布，按实际授权显示，标注统计截至时间（浏览器本地时间），不代表设备在线。网络错误会同时清空当前实时与历史内容。

这使用 Halo 自带代码注入扩展点，**不是独立 Java 插件**。配置保存在 Halo 系统设置，升级主题不会覆盖它；更换主题需要新主题支持 `halo:footer`。不要同时保留旧模板插入片段。其他博客只要能插入 HTML 并配置同源代理，也可复用同一组件。

localStorage 仅保存界面偏好（卡片、各设备/类别/歌词折叠、位置），不保存歌词或个人状态；存储不可用时仍可操作。不同域名分别记忆，窗口缩小时自动限制位置。组件没有远程操作播放器的能力。

完整行为与测试边界见 [0.15 公开卡片](../../docs/PUBLIC-WIDGET-0.15.md)。
