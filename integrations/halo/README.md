# Halo 浮动音乐组件（0.6）

推荐使用 Halo Console → 系统设置 → 代码注入 → 页脚，加入：

```html
<script defer src="/presence/widget.js?v=0.6.0"></script>
```

组件自动挂载到 body，默认位于右下方，不插入文章流。支持拖动、方向键移动、收起/展开、歌词折叠、恢复位置，跟随博客的文字和背景颜色。只读组件不会远程操作播放器。

此方式使用 Halo 自带扩展点，不是独立 Java 插件。配置保存在 Halo 系统设置中，覆盖升级当前主题不会删掉它；切换主题需要新主题支持 `halo:footer`。切勿同时保留旧的模板嵌入片段。若未来需要插件管理开关或独立配置面板，可再包装为 Halo 插件。

每个博客域名均须转发同源 `/presence/*` 到 State of Me；只在一个域名配置路由会导致其他域名无法加载脚本和接口。其他博客也可使用该同源脚本；没有硬编码域名或身份。

公开字段应显式配置为 `music`、`lyric`、`lyric_window`，并选择设备。窗口最多 16 行、未来 60 秒，短歌词可能完整落入窗口。客户端每帧推进当前句，5 秒校准，断网或失联过期清空。电量和屏幕等 `device_state` 是独立权限，本组件不读取它。

组件不携带令牌和 Cookie，不保存歌词和个人状态到浏览器存储。脚本加载后自动创建一个 `state-of-me-status`，不会重复创建。主题样式通过 Shadow DOM 隔离。
