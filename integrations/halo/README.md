# Halo 常驻公开状态组件

将 embed.html 插入当前主题公共布局，在 header 后或侧栏中。可配置同源 endpoint；组件通过 Shadow DOM 隔离样式，不依赖 Halo 或指定主题，也可嵌入其他博客。

公开配置示例：`{"enabled":true,"devices":["phone"],"fields":["music"]}`。必须主动选择设备；默认仍关闭公开接口。此配置公开歌曲、歌手、播放器、播放状态和进度，不公开应用活动、歌词或身份绑定。组件只呈现歌曲、歌手与播放状态。所有其他读者权限保持独立。

组件不携带令牌、不发送 Cookie、不使用浏览器持久缓存，失败/TTL 到期立即隐藏旧内容。5 秒刷新。主题升级可能覆盖模板改动，应保留片段并重应用；需要跨主题自动保留时，可通过 Halo 系统代码注入添加组件，依赖主题保留 halo:footer。当前仓库不伪装成已安装的 Halo 插件。
