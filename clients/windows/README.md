# State of Me Windows 0.17.0 开发预览

适用 Windows 10/11 x64。此发行包包含运行时，不必另装 .NET。

1. 更新时先在旧版本托盘菜单选择“退出”，再解压并运行 `StateOfMe.exe`。原采集配置保留。
2. 新用户在“设置”填写维护者提供的 HTTPS 服务地址，直接登录或注册。
3. 注册后先将恢复码保存到私密位置，再点击“将本机添加到账号”。已有账号登录后自动添加本机；已有设备只需登录所属账号即可管理权限，不会重新注册或静默换人。
4. 在“采集”选择本机应用、设备信息、播放器和歌词目录，点击“保存采集设置”。再到“概览”点击“开始同步”；保存配置不会自动开启同步，新设备默认暂停。
5. 在“分享 → QQ 群”输入群号，生成验证命令并复制到 QQ；返回点击“刷新验证结果”，核对真实 QQ 和群号后确认。新群还需读取分享范围、勾选字段并保存。原有已授权群的范围会保留。
6. “分享 → 公开展示”按字段选择公开数据，保存前会列出公开内容。全部不选即关闭公开。服务器没有接入的群需由维护者配置，普通用户输入群号不会自动给机器人开通新群。

账号管理会话与后台采集凭据分离，均使用 Windows 当前用户 DPAPI 保护；账号会话额外绑定服务地址。账号管理会话过期需要重新登录，设备同步仍按原设置运行。“退出账号管理”只退出管理会话；设置页“断开此设备”则停止并撤销本机采集连接。

公开范围与群范围由服务器统一保存，手机、Windows 和网页都能管理同一套设置。多个入口同时修改时，服务器会检测版本冲突；客户端保留当前选择并提示刷新，防止静默覆盖其他设备刚保存的授权。查看新范围前请先保存有意保留的修改。

忘记密码时可在“设置”的登录区域展开“使用恢复码”，填写新密码。重置会撤销全部会话与设备连接；先保存新的恢复码，再明确断开本机旧连接并重新登录登记，各设备均需重新连接。

窗口关闭后留在托盘继续运行。暂停同步会清空当前状态；“断开此设备”会停止同步并清除旧账号的本地采集选择、手动状态和歌词目录索引，音乐文件保留。

应用采集支持白名单和黑名单。白名单不勾选应用时不采集；黑名单不勾选应用时采集任意可读取的前台应用。修改后点击“保存采集设置”，同步运行状态保持不变。输入空闲不会隐藏仍在显示的前台应用；锁屏、屏幕关闭和应用过滤仍会隐藏它。

前台应用附带输入空闲、窗口层级、置顶、最大化和覆盖当前显示器范围的信息，用于群查询的上下文。层级只统计前方可见且未最小化、未被系统隐藏的窗口，不表示遮挡面积或眼睛注视位置；不上传其他窗口列表或窗口标题。这些字段仅在账号明确选中公开时才向访客展示。

可选 WhatPulse 仅使用本机 API，不安装或不开启该项也可以正常使用。长期凭据使用 Windows 当前用户 DPAPI 保存。设备通过原生账号登录登记；网络重试使用同一登记标识，避免重复设备。

WhatPulse 使用本机 `/v1/all-stats`，约 20 秒一次读取账号累计与排名、本机未 Pulse 累计、原始实时速率、空闲和 Profile。概览展开“完整 WhatPulse 数据”查看所有已提供字段。账号总量随 Pulse 更新，可能包含其他电脑；实时原始速率与采样差值速率独立标注。没有按日期查询历史数据的接口，因此不提供伪造的今日/7日/年度统计。新增字段默认不公开，分享目录由服务端提供。字段清单见 `docs/WHATPULSE-0.17.md`。
