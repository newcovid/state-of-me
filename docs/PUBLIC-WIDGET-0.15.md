# 公开浮动卡片 0.15

通过 [Halo 接入说明](../integrations/halo/README.md) 嵌入一个自定义元素和一份 `widget.js`，无需独立页面或主题模板补丁。数据来自指定账号的无凭据公开接口；账号拥有者在 Android、Windows 或网页选择公开字段。

- 按设备和类别折叠显示实际返回的所有字段：应用、设备电源、活跃状态、手动状态、网络、声音、资源、显示、WhatPulse 和采集诊断。未知类别／字段安全显示原键与文本，避免后端扩展后静默丢失。明确的 `false` 与 `0` 保留，未返回的字段不补默认值。
- 设备名称未授权时显示“设备 1”等编号，不把内部设备 ID 当作名称。每台正在播放的设备各自展示标题、歌手、专辑、歌词与进度；仅标题或仅歌词授权也能显示，不要求一整个音乐对象。没有进度／时长时隐藏对应控件，不产生 NaN 或猜测剩余时间。
- 歌词在页面内存中使用有界窗口连续推进，接口每 5 秒校准。暂停、停止、状态过期时，标题、歌词和进度一起撤回。窗口范围之外不外推歌词。
- 历史统计与实时卡片分开展示，可分别只有每日汇总、应用排行或小时分布。每个历史设备标注统计截至日期时间，使用浏览器本地时区；不根据历史记录判断设备在线。统计缺项不是零，屏幕交互时长也不是眼睛注视时长。
- 默认收起，保留卡片、设备、类别和歌词折叠偏好，支持鼠标／触摸拖动、键盘方向键移动、恢复位置和小屏限制。颜色跟随博客的属性、类、系统明暗与过渡变化。
- 同源拉取、`credentials: omit`、`cache: no-store`。请求失败或无法解析时清空实时与历史缓存；实时设备逐个按 TTL 过期。动态数据使用 `textContent` 插入，不执行歌曲、歌词、应用或状态文字中的 HTML。
- localStorage 只保存界面偏好，不保存状态、歌词或历史统计内容。公开内容一旦被访客读取，仍可能被对方另行复制；撤回授权限制后续读取，无法回收他人的副本。

`node server/test_widget.cjs` 覆盖多媒体设备、未知字段、独立字段授权、零值与 false、进度缺失、歌词窗口边界、安全 DOM 文本、历史截至时间和失败清空。自动检查不替代真实主题和触屏环境的视觉体验验收。
