# Windows 桌面端 0.10 开发预览

本版实现桌面规划 M1 与 M2 的核心采集闭环，并接入 WhatPulse。Windows 10 2004 或更高版本，普通用户权限运行；便携 win-x64 包包含 .NET 运行时。使用实际 WPF UI 4.3.0 Fluent 组件库，跟随系统深浅色。不是长期稳定性已验收的正式版。

## 安装与使用

解压整个压缩包后运行 StateOfMe.exe，保留旁边 DLL。不要单独移动 EXE。连接页填写 HTTPS 服务根地址与此电脑专用写入令牌。凭据用当前 Windows 用户 DPAPI 保护，配置在 `%LOCALAPPDATA%/StateOfMe/settings.json`，不可跨用户直接复制。

分享页提供运行中应用名称、图标、多选、搜索、展示别名、白名单/黑名单/关闭。已选但退出的应用保留；未打开过的应用先运行后刷新。它不是完整已安装软件目录。默认白名单为空、新类别关闭；部署实例可预置已有权限。隐私过滤还有服务端第二层名单，客户端放行不意味着服务器必然放行。

媒体页刷新系统播放器会话，选择允许分享的播放器及优先项。只有播放中才上传；视频和未知媒体保留实际类型，不猜成歌曲。没有有效时间线就不显示推算进度。通过授权目录索引 MP3/FLAC/M4A/OGG/OPUS/WMA 的 TagLib 支持标签、ID3 SYLT/USLT/自定义歌词及同名 LRC；曲名、非空歌手、可用专辑和时长严格匹配，多个候选拒绝猜测。歌词解析缓存于内存，最多 16 行/未来 60 秒窗口。纯文本只报告无时间轴。添加文件后点击刷新歌词索引。索引限制 50,000 个媒体文件，跳过目录链接，不扫描未选择的目录。

概览支持短状态（保存后 1 小时到期）、15 分钟隐身、上传预览及受众预览。只读令牌留在内存，空令牌查询公开投影。关闭窗口收至托盘；托盘退出会暂停并尝试清空。登录启动默认关闭且仅写当前用户启动项。

## 已接入字段

- `app/app_details`：前台应用与标签、当前片段时长。锁屏、灭屏或超过空闲阈值不上传前台应用。
- `music`：标准 GSMTC 播放信息、媒体类型、是否有可靠进度、歌词窗口；不控制播放器。
- `presence`：active/idle/locked/unknown、空闲秒数。
- `manual_status`：用户自述、绝对过期时间；服务端独立校验有效期。
- `device_state`：有无电池、电量、充电、AC 接入、锁屏、节能、屏幕电源通知。部分硬件信息可能缺失。
- `network`：联网、系统互联网验证、计费类型、网卡传输类型。VPN 仅按系统暴露的 PPP/tunnel 信息判断，不声称识别所有虚拟网卡。
- `audio`：默认输出音量、静音、活跃输出会话数量、扬声器/耳机/耳麦等设备形式，其余为 other，不猜蓝牙/USB/有线。
- `resources`：CPU 采样区间占用、内存、系统卷空间；磁盘空间缓存 5 分钟。
- `display`：显示器数量、远程会话、前台全屏。全屏不等于游戏。
- `usage_summary`：WhatPulse 未 Pulse 累计键/点击/滚轮/流量/运行秒数，以及相邻采样窗口的键鼠/流量平均速率。不是今日统计，也不读取输入内容。

GPU/温度/风扇、电池损耗、摄像头/麦克风占用、浏览器/IDE/游戏深度上下文、OBS、历史日统计属于后续可选适配，不包含在此次 M1/M2 核心范围。

## WhatPulse

需自行启用 Client API，并允许本机回环连接。只访问 `127.0.0.1` 上用户配置的 HTTP 端口，默认 3490；禁用代理、重定向，设置大小与超时限制。每 20 秒读取一次 `/v1/unpulsed`。数字字段计算速率，避免依赖本地化速度字符串。任一连续计数回退、采样断档或 API 失败后不跨边界计算速率。未发现的 Pulse 后计数已追平情况不能完全识别，因此速率属于观测区间估算，不作为审计账本。连接失败退避至最多 5 分钟；WhatPulse 退出不影响其他来源。

## 同步与隐私

前台/媒体/会话/电源事件合并，正常请求间隔至少约 1.2 秒；5 秒本地空闲检查，20 秒保活，诊断缓存 20 秒，网络失败退避 5 秒至 5 分钟。未改变的播放进度、空闲时长、资源数值和累计统计不会单独触发上传。歌词窗口接近结束提前补充。休眠不唤醒机器；恢复刷新，服务端 45 秒失联过期，不补发历史队列。

新增上下文先经设备写入权限，再经受众类别/子字段授权。新增电脑未加入公开设备列表，旧博客权限保持原样。私有网页和 AstrBot 能读取已授权的新类别；一般问近况时不主动播报计数和诊断，明确问统计才展开。缺失不是否定，电脑空闲不推断本人离开；设备间数据不混用。

协议兼容：旧 Android 无须升级，仍支持原快照；新增字段为可选。`music.media_kind` 默认 music 保持旧客户端语义，Windows 使用实际来源类型；`position_known=false` 禁止服务端和网页外推时间。受众撤权会即时重新投影，暂停完整撤回新增类别。

## 工程与验证

构建：`dotnet build clients/windows -c Release`。当前工程使用本机已有 .NET 8 SDK；后续运行时维护需跟进支持周期。

测试：`dotnet run --project tests/windows -c Release`；Python 后端与 AstrBot 契约；Node 网页模型与进度测试。`StateOfMe.exe --probe ABSOLUTE_PATH` 可将本机非应用内容诊断快照写到指定本地文件，不上传；该文件可能含个人统计，应自行保管。

打包：`powershell -File clients/windows/build.ps1`。TagLibSharp LGPL 依赖保持独立 DLL 可替换，包内提供许可证，发布页面另附对应版本完整源码压缩包。不要把私有配置、探针输出、令牌加入发行包。

本次验证包括真实 WhatPulse API、原生快照通过后端模型、桌面与手机并存、DPAPI 往返、去重/退避、歌词解析边界、统计重置、权限投影/到期/清空、实际深色窗口与托盘。短时资源样本不能替代长期电量测量。真实多播放器/音乐库、亮色模式、高 DPI/多显示器、休眠后恢复与 24–72 小时稳定性仍需体验验收。
