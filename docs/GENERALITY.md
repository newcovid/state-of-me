# 0.11 通用性审查

核心服务支持多账号、每账号多设备、按群和公开范围授权。代码不绑定特定 QQ、群号、Poweramp、博客域名或服务器路径。客户端不预填某个真实服务器，服务地址由用户选择。当前可复用范围如下：

| 层次 | 通用能力 | 边界 |
| --- | --- | --- |
| 服务端 | HTTP/JSON、注册/恢复、短码配对、设备隔离、群投影、公开投影、TTL | 默认注册上限 100、每账号 10 设备；无邮箱/OAuth/管理后台/自助删号 |
| Android | 标准 MediaSession、UsageStats、SAF；Miuix 组件；免 Root | 播放器需提供元数据；OnePlus Android 16 实测不能代表所有 ROM |
| 歌词 | MP3、FLAC、M4A 内嵌标签与同步窗口 | 特殊标签、逐字时间轴和含糊匹配仍有限制 |
| Windows | Fluent 组件、托盘、进程/媒体、歌词、电源/空闲/网络/声音/资源、可选 WhatPulse | Windows 10/11 x64；尚无 Linux/macOS 采集器 |
| 网页/博客 | 任意用户的显式公开 API；同源浮动组件；主题跟随 | 轮询，无历史活动库；Halo 使用代码注入而非 Java 插件 |
| AstrBot | 真实发送者/真实 @/实时群主、独立用户绑定、群授权 | 目前 QQ aiocqhttp + 中文目标解析；其他平台需身份适配 |

## 首次搭建

唯一推荐入口是 [快速入门](QUICKSTART.md)。`deploy/init_config.py` 从自己的 HTTPS URL 和可选群号生成配套配置，没有原维护者设备或占位写入令牌；自动设置正确 origin，拒绝覆盖已有文件。Docker 使用非 root 用户，文档给出 UID 10001 权限、独立域名/子路径代理及容器代理注意事项。Halo 给出完整自定义元素片段，AstrBot 给出配套配置和非默认路径变量。

## 身份与隐私

“我”来自发送者，“群主”来自实时 QQ 群角色；明确 @ 或 QQ 号来自当前消息。机器人持群服务凭据，只能请求该群已授权用户的数据。绑定候选必须再由网页登录者确认。普通用户不能声明某设备属于他人；客户端写入身份来自配对后的凭据。每次请求均按账号或群授权确定读取范围。

中文规则不是完整自然语言指代解析：例如“他呢”仍会追问，含多个目标时要求明确。`get_my_status` 名称为兼容工具配置保留，实际语义为查询本条消息指定的人。

## 验证边界

自动化覆盖账户隔离和权限。一次真实手机验证只证明该设备的已授权状态与升级路径；其他厂商授权、长期后台稳定性和耗电仍需扩大实测。自托管部署检查与验证记录见 [0.11 验证说明](MULTIUSER-0.11-VERIFICATION.md)。本版适合小群、自建体验，不代表完整 SaaS 身份服务或全平台客户端。
