# State of Me 0.15 内部体验包

本版同步更新后端、网页、AstrBot、Android 和 Windows。属于开发预览，优先完成真实使用验证。

## 安装

- Android：`state-of-me-0.15.0.apk`，Android 8 及以上。使用同一开发签名，可覆盖旧预览版本。
- Windows：`state-of-me-windows-0.15.0-win-x64.zip`，Windows 10/11 x64。先在旧程序托盘选择退出，再解压运行新目录的 `StateOfMe.exe`。无需安装 .NET。
- `TagLibSharp-2.3.0-source.tar.gz` 是 LGPL 依赖对应源码；保留与 Windows 包同时分发。包内另有许可证与第三方声明。
- `SHA256SUMS.txt` 供核对传输完整性，不代表第三方安全认证。

服务地址由维护者提供，支持独立域名或 HTTPS 子路径。客户端不会预填个人服务器。完整步骤见 [多用户说明](MULTIUSER-0.15.md) 与 [自建教程](QUICKSTART.md)。

## 本次体验重点

1. 在客户端账号页登录，确认本机复用自己的设备。新用户注册后保存恢复码。
2. 采集页按需选择本机信息和系统权限；账号页分别选择公开范围和每个 QQ 群的字段。
3. QQ 身份验证成功后默认没有分享字段，需明确勾选并保存。
4. 在另一端修改授权，再尝试保存旧草稿，应提示冲突并保留草稿。
5. 公开卡片只展示已选择且设备实际上传的信息。音乐仅播放中出现；历史统计单独标明截至时间。
6. 退出账号管理不停止设备采集；停止采集、断开设备、移除设备与撤回某群授权分别有独立含义。

## 验证与边界

后端与机器人 69 项测试通过，覆盖租户隔离、字段投影、登记幂等、撤销防复活、授权并发快照与恢复密码并发。网页脚本测试覆盖局部媒体、全类别、多设备、历史时间、安全文本、缓存清空与不跳动通知。Windows 编译和会话隔离测试通过；Android Release 构建与 lint 通过，仍有已记录的非阻断 lint 警告。

在真实 HTTPS 服务使用一次性合成测试账号验证注册、登记重试、精确公开字段、范围冲突、撤销和退出，测试账号随后删除。Android 已覆盖安装并检查真实界面；博客卡片采用合成数据视觉验收。真实 QQ 群对话需要使用者在重新授权后验收；不会通过测试自动打开用户的真实分享范围。长期后台、不同厂商设备和全部 Windows 显示缩放仍需体验反馈。

0.15 删除旧设备短码配对、旧公开开关、旧统计授权接口。生产切换备份后清空旧群/公开范围，账号、设备登记与本机采集设置仍保留。没有运行时旧范围迁移层。今后新增字段不会自动加入已经保存的授权。
