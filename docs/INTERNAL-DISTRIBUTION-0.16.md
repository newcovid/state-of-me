# State of Me 0.16 客户端内部体验包

本版重设计 Android 与 Windows 的页面职责、导航及操作布局，服务端、网页和 AstrBot 继续使用已经部署的 0.15 协议。

## 安装

- Android：state-of-me-0.16.0.apk，Android 8+，同一开发签名可覆盖安装。
- Windows：state-of-me-windows-0.16.0-win-x64.zip，Windows 10/11 x64；先从旧实例托盘退出，再运行新目录的 StateOfMe.exe。自包含包无需安装 .NET。
- TagLibSharp-2.3.0-source.tar.gz 与 Windows 包一起分发，包内包含第三方许可。
- SHA256SUMS.txt 用于核对传输文件。

## 新布局

| 页 | 用途 |
| --- | --- |
| 概览 | 同步运行控制、当前内容、统计结果；Windows 临时状态 |
| 采集 | 应用过滤、播放器与歌词目录、设备信息、统计来源/同步、所需权限 |
| 分享 | 公开访客和各QQ群的字段范围、QQ身份验证、访客预览 |
| 设置 | 服务账号、恢复、设备管理、退出管理、断开本机、启动 |

上传到自己账号叫同步；向访客或群开放读取叫分享。修改采集设置不会自动恢复暂停的同步。各受众授权仍为显式字段，不会因本次更新自动公开数据。

Android 使用 Miuix 底部导航和紧凑页标题，键盘显示时隐藏底部导航并保留内容避让。Windows 使用 WPF UI 侧边导航，账号管理嵌入主窗口。切页保留滚动位置和范围草稿。详见 [统一设计计划](CLIENT-UX-0.16-PLAN.md)、[Android](ANDROID-LAYOUT-0.16.md)、[Windows](WINDOWS-LAYOUT-0.16.md)。

## 验收范围

独立代理先审信息架构，再检查实现和修正后的流程。重点验证保存不启动同步、跨受众草稿不被刷新覆盖、恢复流程入口、歌词索引目标、Android旋转后名单草稿和输入法。

Android 已进行一加真机的导航、键盘和大字号检查。Windows 已查看副屏概览，其他页面实际点按与缩放验证按用户要求延期；编译及状态行为测试不能替代这部分验收。真实账号登录和受众授权由用户输入凭据及选择范围，测试不擅自打开真实数据分享。

如果此前从0.15切换，服务端旧分享范围已清空。进入设置登录账号，再到分享选择公开及QQ群字段即可，不需要回退旧配对流程。
