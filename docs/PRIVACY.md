# 隐私与预览边界

本地白名单先过滤再联网，服务端再次校验并按读者字段投影。默认不采集窗口标题、通知正文、位置、屏幕、音频或聊天。SQLite 仅保留每设备最新快照，不记录活动历史。SQLite WAL 和操作系统备份不是安全擦除保证。

Android 通知访问是系统授予的较大权限，但代码仅调用媒体会话 API。客户端令牌存于应用私有 SharedPreferences，禁止系统备份；Root/被攻陷设备不在凭据保护保证内。电脑/网页令牌只存在内存。令牌不放进 URL、日志、公开截图或仓库。

客户端必须显式开始；应用白名单默认空；公共接口默认禁用。服务器配置决定受众权限。暂停写入隐藏快照；离线最多 45 秒保留最后状态。锁屏不清空音乐（可以锁屏听歌），会隐藏应用。严格隐身请暂停。

媒体报告播放不证明本人正在听；前台/UsageStats 可能受 ROM、分屏、权限和事件缺失影响。暂停播放器的曲名可保留并显示已暂停。网页进度以最近一次采样为准，不伪造实时歌词。

开发预览没有账户系统、配对码、历史存储和正式发布签名流程；适合可信任的单人自托管。不得使用模型判断管理授权。安全问题请私下联系维护者，不公开凭据或私密活动。

0.2：用户通过系统 SAF 选择音乐目录。URI、曲名、歌手、专辑和时长索引仅保存于应用私有目录，音频和完整歌词不上传；只有获准受众可读的当前句出机。目录索引最多 10000 项/12 层，标签解析最多 8MB，歌词最多 256KB。撤销授权清除本地索引并使歌词缓存失效，联网时下一次采样撤回旧句。身份配置与 QQ 号保留于私有部署文件，不进入公开仓库。
