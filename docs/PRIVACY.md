# 隐私与预览边界

本地白名单先过滤再联网，服务端再次校验并按读者字段投影。默认不采集窗口标题、通知正文、位置、屏幕、音频或聊天。SQLite 仅保留每设备最新快照，不记录活动历史。SQLite WAL 和操作系统备份不是安全擦除保证。

Android 通知访问是系统授予的较大权限，但代码仅调用媒体会话 API。客户端令牌存于应用私有 SharedPreferences，禁止系统备份；Root/被攻陷设备不在凭据保护保证内。Windows 设备凭据由当前用户 DPAPI 保护；网页使用 Secure、HttpOnly、SameSite 会话 Cookie。令牌不放进 URL、日志、公开截图或仓库。

客户端必须显式开始；应用白名单默认空；公共接口默认禁用。配对设备属于对应账号，群查询与公开分享分别由账号授权。暂停写入隐藏快照；离线最多 45 秒保留最后状态。锁屏不清空音乐（可以锁屏听歌），会隐藏应用。严格隐身请暂停。

媒体报告播放不证明本人正在听；前台/UsageStats 可能受 ROM、分屏、权限和事件缺失影响。仅正在播放的媒体对外展示。网页进度以最近一次采样为准，不伪造实时歌词。

账号支持短期设备配对与经真实群消息确认的 QQ 绑定；移除设备、撤回群授权或关闭公开分享会限制后续读取。恢复账号会撤销已有登录与设备连接。此开发预览没有活动历史库，尚未建立正式签名发行与安全审计流程。不得使用模型判断管理授权。安全问题请私下联系维护者，不公开凭据或私密活动。

0.3：用户通过系统 SAF 选择音乐目录。URI、曲名、歌手、专辑和时长索引仅保存于应用私有目录，音频不上传；同步歌词上传当前句和有界预取窗口（最多 16 行、未来 60 秒；短歌词可能全部落入窗口）。读取整个窗口需要单独的 lyric_window 权限，只有 lyric 权限的受众仅获得当前句。目录索引最多 10000 项/12 层，标签解析最多 8MB，歌词最多 256KB。撤销授权清除本地索引并使歌词缓存失效，联网时下一次采样撤回旧句。账号、设备归属与 QQ 绑定保存在私有数据库，不进入公开仓库。
