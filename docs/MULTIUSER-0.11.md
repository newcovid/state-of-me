# 0.11 多用户开发预览

## 群友如何使用

1. 安装 Android 或 Windows 客户端，在连接页填写服务地址。使用当前演示服务可填 `https://mchaut.top/presence`；自建服务填写自己的地址。
2. 点击“连接账号 / 注册”。浏览器打开账号页。注册账号名及至少 10 字符的密码，私密保存一次显示的恢复码。
3. 核对网页显示的设备和账号，确认添加；回到客户端再次核对账号，完成连接。连接后分享默认暂停。
4. 选择分享应用/播放器和可选信息。Android 在权限页按需授权；返回后自动显示已授权。音乐目录单独授权，不必 Root。
5. 开始分享。账号页面可查看自己的状态、移除设备和管理授权。
6. 要让 QQ 群查询：在账号页选择群，勾选基本状态范围，生成并复制 `/状态绑定 XXXXXXXX`。在该群发送命令（平台要求唤醒时同时 @机器人），然后回账号页刷新，核对真实 QQ 和群号后确认。之后可以问“我在干什么”，或让群友 @你查询。群主查询仍实时读取 QQ 群角色。

新账号默认不公开、未授权任何群。群及公开基本范围包含账号所有已连接设备（包括以后连接的设备）的应用名称、正在播放与歌词、电量/充电/锁屏、活跃/空闲、手动状态；不包含网络、CPU、WhatPulse、采集诊断。设备本机没有开启的类别不会上传。暂停/停止播放不会展示历史暂停歌曲。

## 状态和操作含义

- 网页退出：只退出网页登录，设备继续按自己的开关分享。
- 客户端暂停：清空当前设备状态，保留连接和选择。
- 移除设备：撤销动态凭据，状态立即不再可读；客户端遇到 401 会停止重试并提示重新连接。
- 客户端断开：停止采集，尝试服务端撤销，清除本机连接、筛选、手动状态和歌词索引；音乐原文件保留。网络失败会明确提示到账号页移除。
- 账号切换：先断开旧设备再连接，避免继承旧账号的采集选择。
- 撤回群授权/公开：下一次查询即不再返回内容，网页已缓存状态仍受短 TTL 限制。
- 忘记密码：恢复码可重设密码；旧网页登录和设备凭据全部撤销，需重新连接。恢复码不能替代 QQ 身份确认。

## 自托管配置

`server/config.example.json` 的 `accounts.registration` 默认关闭。维护者显式开启后允许注册；`max_users` 默认 100，每账号最多 10 台设备。`origin` 填浏览器外部 origin（例如 `https://example.com`，不带路径）。保持 HTTPS，代理不要缓存账号与状态响应。

```json
"accounts": {
  "registration": true,
  "max_users": 100,
  "origin": "https://example.com",
  "bot_groups": {
    "123456": {
      "token": "INDEPENDENT_RANDOM_BOT_SERVICE_SECRET"
    }
  }
}
```

AstrBot 的私有配置对应群设置 `bot_token`，与上面群 token 对应。此密钥由维护者在服务端配置，不交给群友。每次查询必须匹配已确认的 QQ 身份与该群的分享授权。

不要开放任意客户端传 QQ 号直接绑定；`/v1/bot/bind` 仅供受信任机器人服务使用。账号持有者必须在网页确认真实消息提交的候选 QQ。一个 QQ 只能属于一个账号，一个账号只能绑定一个 QQ，可授权多个已接入群。

## API

- 账号：`/v1/accounts/register|login|logout|recover|me|status`。网页会话为 Secure/HttpOnly/SameSite Cookie；变更请求需要同源及 `X-SOM-CSRF: 1`。
- 配对：`POST /v1/pairings` 返回 10 分钟短码和客户端秘密；账号页核对 `/v1/accounts/pairings/{code}` 后 `/v1/pairings/approve`（附当前账号名）；客户端持秘密 `/v1/pairings/poll` 获取动态设备凭据。
- 写入仍为 `POST /v1/events`，设备不能声明自己属于哪个账号。
- 设备：`POST /v1/accounts/devices/revoke`；客户端 `POST /v1/device/disconnect`。
- QQ：账号生成 `/v1/accounts/bind-code`，机器人 `/v1/bot/bind` 提交实际发送者，账号 `/v1/accounts/bind-confirm` 确认；`/v1/bot/status/{qq}?group_id=...` 仅返回该账号向该群授权的投影。
- 公开：显式开启 `/v1/accounts/public` 后，`GET /v1/public/users/{name}`；页面 `/?user=账号名`。每个公开入口只读取该账号的设备。

SQLite 保存密码慢哈希、会话/动态凭据/恢复码的 SHA256 摘要。Android 短期配对秘密保存在应用私有数据中，过期/完成/取消清除，系统备份关闭；Windows 长期凭据使用 DPAPI，序列化排除明文 Token。账号和配对有速率/容量限制，但本版未实现邮箱、社交 OAuth、自助删号和管理后台；适合小规模自托管开发预览，不承诺大规模公共身份服务容量。

## 验证边界

自动化覆盖双账号隔离、默认私密、设备撤销/短码失效、独立机器人服务凭据、QQ 二次确认、按群授权、恢复码轮换及 CSRF。客户端构建、UI 检查和服务器健康不替代不同厂商手机授权实测。实际群消息验证应由用户完成，开发过程不向群发送测试聊天。
