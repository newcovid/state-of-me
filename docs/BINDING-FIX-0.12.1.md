# 0.12.1 群绑定与账号页交互修复

绑定由 AstrBot 的 `state_of_me` 插件处理，NoneBot 没有 State of Me 适配插件。此前使用标准命令过滤器，受 AstrBot 的 `wake_prefix` 限制；当唤醒前缀是 `/ab ` 而网页生成 `/状态绑定 …` 时，消息能够进入框架但不会进入绑定处理。

绑定入口改用完整匹配的正则过滤器，接受 `/状态绑定 八位码` 与 `状态绑定 八位码`。它不依赖聊天唤醒前缀，不匹配解释、搜索或带额外参数的自然语言。绑定仍读取真实群消息的发送者和群号，经服务端校验后由账号页面再次确认；错误响应区分过期码、冲突、接入配置和服务不可用。

账号页使用底部浮动通知，可手动关闭并在 8 秒后消失。普通输入、状态刷新及通知不调用滚动；只有明确的导航按钮才定位到相应区块。QQ群号改为文本输入加可选建议，修改群号会清除旧命令并要求重新确认分享范围。服务端拒绝尚未接入的群，不会因输入群号而扩大机器人权限。

验证：52 项 Python 测试及 Node 歌词、组件、账号交互测试通过；使用服务器实际安装的 AstrBot RegexFilter 验证了未唤醒状态下的命令匹配与实际发送者传递（网络模拟，未发送 QQ 消息）。浏览器中浮窗显示前后滚动位置一致。生产页面与插件已更新；客户端版本仍为 0.12.0，本次无需重装 App。
