# 桌面端开发规划

日期：2026-10-24。状态：M1/M2 核心闭环已实现为 0.10 开发预览，实际支持范围与待验收边界见 [版本说明](DESKTOP-0.10.md)。首个平台 Windows，核心协议和采集器接口保持跨平台。本文覆盖候选能力，不意味着默认启用所有采集或对外发布。

## 现状

clients/windows 是 .NET 8 / WPF 0.1 原型：每 5 秒上传白名单前台进程名；锁屏或空闲 3 分钟隐藏应用；暂停/退出尝试清空。没有音乐、持久配置、应用多选、托盘、重试退避或状态去重。server/app.py 已有 music、app_details、device_state、network、audio、resources、collector_health，仍存在 Android 专用字段和严格 extra=forbid 约束，扩展必须先发布兼容后端。

## 设计约束

- 普通用户权限运行。采集器可独立开关；不支持、权限不足、采集失败与明确否定分开表达。
- 本地采集授权、上传字段授权、受众展示授权三个独立层级。新增字段与新设备默认不公开；手机既有公开权限不能自动套用到电脑。
- 应用选择使用名称、图标和多选名单；支持关闭、白名单、黑名单、单应用覆盖和自定义展示别名。进程路径仅用于本地身份匹配，不默认上传。
- 只对外发布正在播放的媒体；暂停/停止立即撤回。无关负面状态不拼成播报。麦克风占用不是会议证据，运行进程不是前台活动证据，空闲不是离开座位的证明。
- 事件驱动、合并去重、20 秒保活、失败指数退避；当前服务器 TTL 45 秒。心跳不唤醒睡眠电脑。恢复后刷新状态；不补发过期活动。歌词窗口不足时允许提前刷新。
- 具体 QQ、域名、设备名称和播放器偏好仅进部署配置，不进入通用规则。

## 采集能力矩阵

P0：首个可体验版本；P1：紧接着完善；P2：可选适配/较高成本增强。

| 类别 | 候选信息 | 来源与限制 | 优先级 / 默认策略 |
|---|---|---|---|
| 前台应用 | 稳定应用标识、名称、图标、本次前台起始时间/持续时间、用户指定类别/别名 | WinEvent 前台事件 + 进程/包身份；宿主、多窗口和权限失败需要降级；图标留本地 | P0，用户选名单后启用 |
| 人机活动 | 活跃/空闲、空闲时长、锁屏、当前交互会话、睡眠/恢复 | 最后输入时间 + 会话/电源事件；不读取按键或鼠标内容；阈值可调 | P0，公开只用粗粒度状态 |
| 音乐与媒体 | 标题、作者、专辑、播放器、播放状态、位置/时长、速率、曲目标识、媒体类型（来源提供时） | GSMTC 标准媒体会话；只覆盖接入系统媒体控件的应用；缺少进度时不伪造 | P0，独立播放器名单 |
| 多播放器 | 所有候选会话、当前选中来源、用户优先级、切换原因 | 优先用户指定，再正在播放与系统当前会话；后台音乐不被暂停视频抢占；候选列表本地 | P0 |
| 歌词 | 同步歌词、当前句、滚动窗口、纯文本、歌词来源和匹配状态 | 授权目录内嵌标签 + 同名 LRC；严格匹配；GSMTC 不保证歌词/文件路径；插件补充 | P1，目录授权后启用 |
| 电源 | 电池电量、是否存在电池、AC 接入、充电、节能模式、电池剩余时间（系统提供时） | 电源通知/系统电源接口；台式机无电池不是 0%；估算剩余时间有不确定性 | P0，分字段选择 |
| 电池健康 | 设计/满充容量、循环次数、损耗估计 | 硬件/驱动支持不一致，不高频 WMI 轮询 | P2，本地诊断 |
| 网络 | 联网状态、传输类型、计费网络、VPN 存在、服务端可达性 | 网络变化事件；本地联网、互联网探测和本站可达性分别表示；不额外频繁探测 | P1，默认私有 |
| 音频 | 默认输出类型、主音量、静音、活跃输出会话 | Core Audio 事件；输出会话活跃不等于有可听声音 | P1，默认私有 |
| 通信占用 | 麦克风占用/静音、通信模式、摄像头占用 | 独立能力探测；系统和应用限制较多，无法可靠获取时 unknown；不采集音视频 | P2，显式启用 |
| 资源 | CPU 使用率、内存总量/可用量、磁盘总量/剩余量 | 低频系统计数器；CPU 需要采样窗口；磁盘空间 5–15 分钟刷新 | P1，本地诊断，上传单独开关 |
| 扩展性能 | GPU 使用率/显存、磁盘 IO、网络速率、温度/风扇 | 计数器/硬件适配；温度风扇通常需额外依赖甚至驱动，不承诺通用 | P2，本地按需诊断 |
| 显示与会话 | 屏幕开关、显示器数量、远程会话、全屏窗口 | 系统事件与窗口几何；多屏/远程桌面有边界，全屏不代表游戏 | P1，诊断优先 |
| 专注/勿扰 | 用户手动忙碌/专注、到期时间；系统专注状态（有公开接口时） | 手动状态可靠；不依赖未公开注册表推断作为核心能力 | 手动 P0，系统适配 P2 |
| 浏览器 | 活动站点名称/域名、可选页面标题、媒体类型 | 浏览器扩展主动提供；默认去路径/查询串/片段，隐身不采集；单站过滤 | P2，显式启用 |
| 编辑器/IDE | 编辑器、语言、用户设定项目别名、构建/调试状态 | VS Code / JetBrains 等插件；不上传源码、完整文件路径、仓库地址、命令行 | P2，显式启用 |
| 游戏 | 游戏名、平台、运行时长；可选模式/局内状态 | 前台应用映射 + 游戏公开 SDK/适配器；不读内存、不注入、不绕过反作弊 | 名称映射 P1，深度信息 P2 |
| 会议/直播 | 正在会议、共享屏幕、直播/录制 | 应用正式接口/用户配置适配器，例如 OBS；仅进程存在不能确认会议或直播 | P2，显式启用 |
| 下载/任务 | 下载中、构建中、渲染中、进度和预计完成时间 | 应用主动发布/本地适配协议；默认只给任务类型，不上传任务文件名 | P2，显式启用 |
| 手动状态 | 自定义短状态、表情、忙碌/离开、到期时间、隐身 | 用户主动输入；明确覆盖规则，隐身优先级最高 | P0 |
| 本地使用统计 | 按应用累计时长、切换次数、活跃/空闲时间、日统计 | 可选本地数据库、保留期/删除/导出；默认只保存当前快照，不上传历史 | P2，显式启用 |
| 采集器健康 | 客户端/协议版本、各采集器能力、最近成功时间、失败原因、上传/跳过次数、字节数、队列、延迟 | 脱敏诊断；不记录令牌和真实活动文本 | P0，本地，私有诊断可选 |

不列入通用采集：键盘内容、剪贴板、聊天/通知正文、屏幕截图/OCR、浏览历史、密码、完整文件目录扫描、定位、联系人、音视频录制。需要上述能力时应作为另一个有明确用途与授权的功能设计，不能由“信息尽量全”隐式启用。

## 原生 API 与兼容契约

1. 保留 app/music 现有字段，先为 device_state 等增加可选通用字段。平台特定 sdk 不强填到 Windows。新增 capabilities 与字段可用性必须版本化；避免一个字段失败使整份状态失效。
2. 候选新增 presence（active/idle/locked 与证据时间）、manual_status、media（通用视频/播客语义）、activity（显式应用适配器上下文）。先完成 JSON 示例、校验、权限投影和旧客户端回归，再启用上传。
3. 来源、采样时间、失效时间与可用性分别表达。在线与最后可见时间由服务端接收时间判断；未知不能编码成 false 或 0。
4. 全量快照保留明确清空语义，新增可选字段不转换为永久累积的补丁。权限撤销与暂停必须撤回已发布字段。恢复联网只发最新状态。
5. 受众按字段授权；机器人仅接收其授权投影，网页也使用相同投影。模型不负责执行权限隔离。
6. 多设备保持独立状态与新鲜度；不得把手机歌曲当电脑歌曲。个人摘要优先明确的前台活动，可同时表达电脑工作与手机音乐，不能从单一设备空闲推断本人无活动。
7. 浏览器/IDE/任务扩展先建立有鉴权、限大小、限频率的本地 IPC 接口；普通 localhost 端口不视为可信。扩展本身可禁用、超时清空。

## 客户端工程与界面

优先延续 C# / WPF、MVVM 与独立采集核心，选择维护中的成熟 Fluent 组件库；实施前验证当前版本、许可和可访问性。Windows 目标版本与 .NET LTS 选择在环境基线阶段确定，不直接沿用原型旧版本。跨平台先保留采集接口与协议，暂不承诺 macOS/Linux 同期交付。

常驻托盘：状态图标、暂停、定时隐身、恢复、设置、彻底退出。关闭窗口与退出行为明确。开机启动可选且默认关闭；普通用户登录会话运行，不做 Session 0 服务采前台窗口。

界面保留：概览（实时本地/上传/各受众预览）、分享（分类开关和应用多选）、媒体（播放器优先级和歌词目录）、连接。诊断折叠到高级页。随系统深浅色、键盘导航、高 DPI、多屏与屏幕阅读器；不把诊断堆进日常界面。令牌使用 Windows 用户级凭据保护，日志脱敏。

## 里程碑与验收

### M0：契约和工程基线
- 构建并审计当前 Windows 原型，选定受支持目标系统/运行时/成熟 UI 库。
- 定义字段、缺失/清空/过期语义、采集与受众权限、多设备示例。
- 新增可选协议先落后端与测试，保留 Android、网页、AstrBot 回归。

### M1：完整桌面最小闭环
- 托盘、持久配置、安全凭据、应用多选过滤、手动隐身。
- 前台/锁屏/空闲/电源与标准媒体会话，事件去重、20 秒保活、失败退避。
- 受众预览；后端与 AstrBot 识别桌面通用字段，网页仅显示明确授权字段。
- 验收前台切换/过滤命中/锁屏/暂停撤回、歌曲暂停立即消失、多媒体竞争、断网/休眠/恢复、双设备同时在线。

### M2：信息覆盖与实际体验
- 授权目录内嵌歌词、播放器匹配、时间锚点和歌词窗口；网络/音频/资源/显示状态。
- 不支持字段按能力报告；非管理员、无电池、多显示器与远程会话降级。
- UI 深浅色/缩放/键盘可达性检查与实体桌面体验。

### M3：扩展生态
- 浏览器、编辑器、游戏/OBS/任务适配器；可选本地统计。
- 每个适配器单独权限和验收，不把所有第三方依赖塞进首包。

### M4：发布与测量
- 契约/策略/投影单元测试与 Windows CI 构建；打包、升级、回滚与签名策略。
- 记录 CPU 时间、私有内存、唤醒次数、上传次数/字节、响应延迟 P50/P95；分别测试静置、应用切换、播放、锁屏、断网。
- 候选目标：静置网络约 3 次/分钟（事件与歌词额外），无无限队列、无每秒磁盘写；实际 CPU/内存基线测完才定预算。
- 有网时事件到服务端目标 P95 < 2 秒（注明测试环境）；断网 TTL 清空；24–72 小时常驻、休眠恢复与多屏验收。
- 发布计数下降不等于耗电同比下降；笔记本电量实验需要相同亮度/负载/电源模式和重复测量。
