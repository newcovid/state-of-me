# 0.4 开发计划

目标：提升播放同步与网页可读性，保持单人自托管、平台无关协议和明确权限边界。

| 阶段 | 工作 | 验收 |
| --- | --- | --- |
| A 设计 | frontend-design 指导，制定色彩、字体、布局及状态规范 | 设计审查记录；不依赖外部字体或个人身份 |
| B 网页 | 音乐阅读区、上下文歌词、设备栏、折叠连接设置、空态/错误指引 | 桌面与窄屏截图、键盘焦点、长文本、断开清空 |
| C 采集 | MediaController 回调触发更新，事件合并、发送间隔控制、5 秒心跳兜底 | 纯 Java 调度测试、Android 构建；不写 Poweramp 私有接口 |
| D 交付 | 合约测试、公开源码、服务备份/部署、预览包 | 健康检查与 CI；实机操作延迟和视觉审美由用户验收 |

本轮按 A–D 执行。设备配对、多用户、其他操作系统列为后续版本，不混入本轮。

## 设计规范与审查

指导来源：anthropics/skills 的 frontend-design；未取得可验证的评分。

色彩：雾蓝 #eaf0f5、纸白 #ffffff、墨蓝 #20354a、静蓝 #49647d、强调蓝 #235d91、分隔线 #c9d6e0。
字体：本机 Segoe UI / 苹方 / 微软雅黑；歌词使用本机宋体回退，字号随视口变化。无字体请求。
布局：左对齐标题与连接设置；主区域音乐占视觉主位，歌词居中；设备名称及更新时间以辅助信息呈现。小屏单列，控件至少 44px。

线框：
```
品牌                       连接设置
此刻的状态                 连接提示
[设备名称 / 应用]
[播放状态  歌曲 / 歌手]
[上一句]
[当前句，主要视觉焦点]
[下一句]
[进度条和时间]
```

审查调整：取消默认大面积深色卡片、装饰渐变与虚构封面，把视觉重点留给真实歌词；无歌词时明确解释原因；不把只读进度条伪装成可远程控制播放器的滑块。

## 通用性约束

核心接口不包含 QQ、人名、域名或指定播放器判断。平台身份留在适配器；只使用标准 MediaSession 回调。保留旧客户端协议兼容及读者窗口权限隔离。回调缺失仍由心跳恢复；本轮不宣称毫秒级同步。
