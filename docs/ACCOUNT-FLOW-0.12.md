# 0.12 账号入口与部署验证

设备统一通过账号页面确认短期配对码，设备身份由配对凭据确定。网页登录使用账号会话；群查询使用经实际 QQ 消息和账号页面双重确认的绑定；公开组件明确指定账号的公开接口。

本版删除静态设备凭据、只读令牌入口、旧读取接口和预设主人身份回退。升级前备份配置与 SQLite 数据库；已有账号与已配对设备保留。仍使用静态凭据的客户端需要更新并连接账号。博客的公开分享开关继续由账号决定。

## 网页操作

1. 登录或切换到注册模式，注册后保存恢复码。
2. 在手机或电脑客户端填写服务地址并连接账号。网页核对设备，客户端确认连接。
3. 回客户端选择内容并开始分享。网页区分等待接收、已配对、已接收过状态。
4. QQ 查询与公开分享分别可选。群命令发送后返回网页确认真实 QQ；公开分享开启后才有公开链接。

页面顶部只突出当前下一步，已连接设备无需重复配对。设备、群授权和公开范围分开管理；支持减少动态效果偏好，样式通过同源 CSS 加载并遵守 CSP。
