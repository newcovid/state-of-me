# 状态查询与桌面前台语义（0.13）

AstrBot 的模型自主决定是否调用 `get_my_status`。插件根据消息发送人、提及对象及群成员角色确认主体，后端校验 QQ 绑定和群授权，再投影新鲜状态。插件不再根据“在干什么”或具体问题的关键词裁剪结果；模型收到完整的已授权快照，自行决定回复重点。身份规则不承担内容选择。

完整快照仍受到设备分享开关、应用过滤、群授权字段、状态有效期和播放状态约束。暂停音乐不会作为当前音乐返回；没有数据不等于人在休息或什么都没做。保持简洁、不逐项播报未发生的活动，是回答指引而不是数据删除规则。

Windows 应用黑名单为空时允许所有可读取的前台应用，白名单为空时不允许任何应用。键鼠空闲阈值仅影响 `presence` 和 `app_details.input_idle`，不再抹掉未锁屏、屏幕未关闭时的前台应用。

`app_details` 新增可选字段：

| 字段 | 含义 |
| --- | --- |
| foreground | 当前前台应用 |
| input_idle | 输入空闲达到用户阈值；不能据此判定人离开 |
| z_order | 排在当前窗口前方、可见且未最小化/未被 DWM 隐藏的窗口数量；无法确定时为空 |
| always_on_top | 该窗口是否具有置顶样式 |
| maximized | 是否最大化 |
| fullscreen | 窗口矩形是否覆盖所在显示器；不等于正在游戏 |

这些字段随应用过滤一起清除，面向已授权的群查询提供；公开网页只保留应用名称。未采集窗口标题、背景窗口应用列表、屏幕图像或注视数据。多显示器和重叠窗口下，层级不代表遮挡比例；当前前台只能作为注意力的间接线索。

本次新增回归覆盖：空黑名单/白名单、授权快照的完整保留、非播放音乐的清除、群窗口上下文与公开投影隔离，以及应用隐藏时一起移除窗口上下文。
