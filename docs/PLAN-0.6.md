# 0.6 浮动组件、输入法与设备状态

## 已实现

- 各博客域名使用同源 API 路由；系统页脚注入加载浮卡，移除旧主题模板片段。
- 浮卡支持指针拖动、方向键移动、收起/展开、歌词展开、位置重置和主题配色。公开音乐与有界歌词窗口，不公开设备状态。
- Android 使用 adjustResize、API 30+ IME/systemBars Insets 和输入框滚动可见区域处理键盘。服务地址使用 URI 键盘，单行输入配置 Next 和禁用全屏提取模式。
- 音乐对象补充 album（专辑）。Android 可选上传 device_state：battery_percent 0–100、charging、screen_on、locked、power_save；字段可空，缺失数据不推断。
- 客户端开关默认关闭，服务端设备规则 device_state 默认关闭，读者需同名字段权限。隐藏事件和权限撤回均遮蔽数据。公开投影单独配置。

## 设计

采用博客自身中性色与文字颜色、唱片标识和歌词阅读层级。右下默认浮动，宽度受视口限制；不播放声音，不伪装成远程播放按钮。保留键盘焦点、拖动替代操作和减弱动效兼容。

## 验收边界

API 合约测试涵盖字段范围、设备授权、受众隔离和隐藏清空；Android 构建和签名验证。浏览器验证实际博客子域名、展开收起、指针拖动和位置恢复。真实手机输入法弹出/收起、大字体和新增采集值仍需要真机体验验证；不能以编译通过替代这些验收。

维护：Halo 系统设置不会随普通主题覆盖升级丢失；切换主题需要保留 halo:footer 扩展点。无需维护主题源码补丁。后端先升级，再安装新版 Android。
