## 新用户

1. 安装 APK；Windows 解压全部文件后运行 `StateOfMe.exe`，不要仅复制 EXE。
2. 在连接页填写维护者给出的 HTTPS 服务地址，点击连接账号／注册。网页注册个人账号，私下保存恢复码，核对配对设备，然后回客户端确认账号。
3. 自己选择分享的应用、播放器与设备信息，再开始分享。只授予使用到的功能所需权限，授权成功会显示状态。
4. Android 的统计页可本地查看屏幕与应用时长；需要云端查询再开启统计同步。每天前 50 个允许分享的应用汇总可同步，不上传原始事件轨迹。
5. 群查询：在账号页填写已接入此服务的群号，按提示完成 QQ 绑定和网页确认。手机使用统计需要在该群下再开启“允许本群查询使用统计”。公开博客与群授权分别控制，统计默认不公开。

升级旧 Windows 时先退出托盘程序，再运行新解压目录中的 EXE。已有设置保存在用户目录中。Android 覆盖安装保留账号、权限和分享选择；不要卸载旧版再装，以免丢失本地设置。

包中不含设备令牌、个人账号、服务器配置、签名私钥或真实使用数据。每位群友需连接自己的账号。
