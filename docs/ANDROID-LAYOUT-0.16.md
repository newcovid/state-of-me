# Android 0.16 布局设计

Android 使用上游 Miuix SmallTopAppBar、NavigationBar/NavigationBarItem、miuix-icons、Preference 和 WindowDialog；保持现有亮暗主题及系统字体缩放。四个一级目的地为概览、采集、分享、设置，取消原有歌词顶层页和账号内部业务 Tab。

- 概览默认实时：开始/暂停本机同步、最近同步结果、45 秒内成功上传内容的本机预览。轻量分段进入使用统计，才读取本地历史；统计页只呈现范围、结果和刷新。首次查看统计允许建立本地汇总，但不自动开启统计上传。
- 采集：应用名单及使用情况权限；播放器及通知访问；歌词目录授权、索引刷新与移除；设备信息；统计同步和清除记录。权限状态就近显示，已授权无需重复请求。黑名单仅涵盖保存时的候选应用，新安装应用需要重新保存；空白名单不上传应用。
- 分享：账号级公开访客与各 QQ 群字段范围，清楚说明影响该账号所有设备。未登录指向设置。新群验证与范围授权分开；字段目录来自服务端，新增字段默认关闭。
- 设置：服务地址、账号登录注册和恢复、设备连接与撤销、退出管理。账号管理会话与设备同步凭据保持独立。

页面采用紧凑标题、16dp 外边距和按任务分组的列表，避免逐项嵌套卡片。底部导航在输入法展开时隐藏，内容保持 IME padding 和独立页面滚动位置；统计分段单独保存滚动位置。

## 状态与安全

ConnectionPage 在稳定调用位置持续组合，切换目的地只改变渲染，不取消进行中的账号请求或登记。分享草稿保存目标、字段、revision 和账号身份，可稍后继续；取消弹窗不等于放弃草稿。账号更换、登出、断开和服务地址改变清除相关草稿。revision 冲突保留本地选择，明确重新读取后才替换。恢复码仍使用 Keystore 加密持久化；设备 enrollment_id 继续按端点和账号保持幂等，旧 token 不静默换归属。

概览使用 Collector 内存中的不可变最近成功上传快照，不增加磁盘活动记录或额外采集请求；暂停、鉴权失效、连接变化、服务停止清除快照，45 秒后 UI 隐藏。预览标注为本机同步预览，不代表访客或群实际可见内容。页面显示不改变公开权限。

## 验证

构建与 Android lint；四页导航和每页滚动恢复；默认概览不触发统计读取；设置登录输入法；大字号；未登录分享入口；草稿稍后继续与跨页返回；冲突和身份隔离由独立审查复核。真实账号登录和授权变更需以用户实际体验为最终验收。
