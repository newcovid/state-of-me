# Windows 0.16.1 用户流程审查

日期：2026-10-25。独立子代理从第一次使用者角度检查客户端源码与四页操作流程；主代理负责副屏上的真实点击和视觉验收。本文中的静态审查不等同于实际用户测试。

## 审查结论与修复

四页职责保持为概览、采集、分享、设置。采集决定本机上传内容，分享决定账号的受众范围，设置负责账号与设备连接。主要问题在操作反馈和下一步指引，而不是需要增加页面。

| 问题 | 用户影响 | 处理 |
| --- | --- | --- |
| 保存恢复码后没有下一步提示 | 误以为注册已完成本机连接 | 明确提示添加本机；恢复码未保存时禁用登记按钮，保存成功刷新按钮状态 |
| 本机登记后缺少采集入口 | 不清楚如何让状态开始出现 | 显示前往采集按钮，说明保存后在概览开始同步 |
| 分享范围看不出已选数量 | 需展开逐项数勾选 | 每组显示已选数与总数，列表显示总体数量，随勾选更新 |
| 字段说明只在悬浮提示中 | 新用户难理解字段含义 | 在字段下面直接显示服务端说明，保持动态目录 |
| 已验证 QQ 页面仍铺满验证动作 | 把一次性操作误当作每次都需执行 | 验证控件收进“在其他群验证”，未生成命令时隐藏空命令框 |
| 公开保存位于长列表末尾 | 修改后难找到保存动作 | 列表顶部和底部使用同一保存函数 |
| 公开范围未直说跨设备生效 | 误以为只影响当前电脑 | 公开和群范围均说明账号、手机、电脑与以后添加设备的关系 |

授权 API、原有确认、默认选中字段、版本冲突保护和恢复码要求保持原有语义。修改不会代替用户保存任何真实公开或群授权。
